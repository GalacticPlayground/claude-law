# United States Code (USC) — Title Index

## How This Corpus Is Organized
The USC is divided into **50 substantive Titles** (+ unnumbered appendices for certain Titles). Each Title covers a distinct subject area of federal law. The reference corpus below catalogs:
- **Title numbers** and the subject matter they cover  
- **Cross-references** to relevant CFR (Code of Federal Regulations) sections

### Reference Indexing Convention
Each corpus file follows the pattern:  
`usc_title_{NNXX}/` → `{subchapter}.md` (where subchapters = chapters, sections of that USC Title; e.g., us_c18/18_07.md = 18 U.S.C. §7)

The **CFR** counterpart to each USC Title lives in `../cfr_regulations/{cfr_title}/`.
