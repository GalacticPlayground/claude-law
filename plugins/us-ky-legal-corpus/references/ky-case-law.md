# Kentucky Case Law — Public Data Sources

**Plugin:** `us-ky-legal-corpus`
**Pulled:** 2026-06-05

On-demand index. No verbatim case text is snapshotted; Claude can call these
APIs at runtime.

## Primary free sources

- **CourtListener** (Free Law Project) — `https://www.courtlistener.com/`
  - All Kentucky appellate + supreme court opinions
  - 13M+ cases, free API: `https://www.courtlistener.com/api/rest/v3/opinion/?cluster__docket__court__id=ky`
  - Filter: `cluster__docket__court__id=*` for Kentucky courts
- **Kentucky Supreme Court** — direct website opinions page
- **Kentucky Court of Appeals** — see court website
- **Justia** — `https://law.justia.com/cases/kentucky/`
- **Google Scholar Case Law** — `https://scholar.google.com/scholar_case`
