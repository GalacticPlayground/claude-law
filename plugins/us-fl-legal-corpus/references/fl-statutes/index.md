# Florida Statutes — Statute Index

**Plugin:** `us-fl-legal-corpus`
**Pulled:** 2026-06-05

This file is the canonical entry point for Florida statutes. It indexes the official
state legislature's code browser, plus the federal eCFR/USC indexes that are
referenced for the four federal practice areas this plugin covers
(consumer-debt, family-law, housing, civil-procedure).

## Official state sources

### Florida Statutes
- <https://www.leg.state.fl.us/Statutes/index.cfm?App_mode=Display_Statute&URL=0000-0099/0001/Sections/0001.001.html>

## State-specific subjects (canonical chapter list)

- **Family Law** — Dissolution, parenting, child support, custody, adoption, PFA / protection orders
- **Consumer Debt** — Collection agencies, garnishment, exemptions, usury, retail installment sales, credit reporting
- **Landlord-Tenant** — Residential tenancies, evictions, rent escrow, security deposits, just-cause
- **Civil Procedure** — Statutes of limitations, venue, service of process, judgments, appeals
- **Criminal Procedure** — Arraignment, preliminary hearing, pretrial, sentencing, post-conviction
- **Evidence** — Privileges, hearsay, expert testimony, character evidence
- **Probate / Estates** — Wills, intestacy, small-estate, conservatorship, guardianship
- **Real Property** — Deeds, recording, foreclosure, HOAs, adverse possession
- **Torts** — Personal injury, wrongful death, products liability, malpractice
- **Contracts** — Statute of frauds, unconscionability, parol evidence, third-party beneficiaries
- **Business** — Corporations, LLCs, partnerships, securities, franchises
