# Kansas State Legal Corpus

Comprehensive, curated corpus of **Kansas** state law.

## Coverage
- **Kansas Statutes** — the state's statutory code
- State-level administrative regulations
- State precedent: Kansas Supreme Court + Court of Appeals
- All embedded county/municipal law layers (Kansas county-by-county)

## Structure

```
us-ks-legal-corpus/
  references/
    ks_statutes/             # Kansas Statutes organized by chapter
    ks_court_rules/          # Statewide + county-specific court rules
  skills/                     # Subject matter + procedural + venue skills
  .claude-plugin              # Plugin manifest
  README.md
```

## How this works
This plugin provides reference corpora for legal research and document production.
All statutory/textual content is kept in `references/` as curated, sourced documents.
