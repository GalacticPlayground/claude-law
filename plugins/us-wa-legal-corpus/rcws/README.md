# RCW (Revised Code of Washington) — Corpus Reference

## Overview

The RCW is the codification of **all permanent general and local laws** enacted by the Washington State Legislature. It's organized into chapters that cover subject matter ranges from constitutional provisions to procedural rules, tax codes, and administrative regulations.

### How This Corpus Is Organized
Each chapter (or set of chapters) is catalogued in `/references/rcws/` using this naming convention:
- `rcw{NN}.md` → RCW chapter(s), e.g., `rcw029a.md` = RCW 29A (Elections)
