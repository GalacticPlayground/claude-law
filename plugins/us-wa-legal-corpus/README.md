# us-wa-legal-corpus

Washington State legal reference corpus for state-law research and drafting support.

> **Not legal advice.** This corpus is a drafting and research aid. Verify all statutes, court rules, deadlines, and municipal provisions against current official sources before relying on them.

## Contents

- `references/wa_constitution/full_text.md` - Washington State Constitution source record and full-text acquisition target from the Washington State Legislature.
- `references/rcws/index.md` - major Revised Code of Washington title and chapter index, with emphasis on civil procedure, courts, consumer, family, property, criminal, administrative, and municipal-law workflows.
- `references/king_county_corp/index.md` - King County Superior Court local-rule index, King County District Court local-rule index, and Seattle Municipal Code index.

## Official Sources

- Washington State Constitution: <https://app.leg.wa.gov/Constitution/>
- Combined Legislature HTML for the Constitution: <https://app.leg.wa.gov/documents/laws/Constitution/State%20Constitution%20Articles%20and%20Amendments%20Combined/WA%20CONSTITUTION.htm>
- Revised Code of Washington: <https://apps.leg.wa.gov/rcw/>
- King County Superior Court local rules: <https://www.courts.wa.gov/court_rules/?fa=court_rules.localsupbycrt&lsc=s17>
- King County District Court local rules: <https://districtcourt.kingcounty.gov/about/local-rules>
- Seattle Municipal Code and City Charter: <https://www.seattle.gov/cityclerk/legislation-and-research/seattle-municipal-code-and-city-charter>

## Refresh Notes

The online RCW is updated by the Code Reviser after legislative sessions and qualifying ballot measures. Local court rules and municipal code provisions can change independently; verify effective dates at the official source before filing or advising.
